# 商业化决策（WP-16）

> 结论先行：**不做广告，不做功能阉割式会员**。核心本地功能永远免费；
> 先接受捐赠，再考虑可选的云同步/团队协作；插件市场在 0.4 前不做。
> 本文是决策记录，代码层不做任何商业化预埋。

## 1. 产品约束

LiteLauncher 的信任模型是“本地优先、装完即用”：

- 搜索、应用启动、截图、剪贴板、日程、笔记都在本机完成；
- 插件可以完全离线，只有用户显式触发网络插件时才联网；
- 用户把 start menu、剪贴板历史、日程交给它，任何“偷偷变现”都会直接破坏信任。

因此排除：

| 模式 | 结论 | 原因 |
|---|---|---|
| 广告 / 推荐位 | **不做** | 与工具类信任冲突；启动器是高频入口，广告会污染每一次搜索 |
| 功能阉割式会员 | **不做** | 核心能力（启动/搜索/截图/剪贴板）必须免费；否则口碑不可逆 |
| 强制账号 | **不做** | 本地工具不该因登录才能用 |
| 默认上传遥测 | **不做** | 隐私叙事是产品差异点；最多做本地可选诊断导出 |

## 2. 路径与优先级

| 路径 | 可行性 | 定价假设 | 启动条件 |
|---|---|---|---|
| 捐赠（GitHub Sponsors / 爱发电） | **高** | 自愿；建议 ¥30/¥50/年档 | 现在就可以放 README/关于页 |
| 付费云同步（日程/笔记/设置） | 中 | ¥15–25/月 或 ¥128–198/年；含有限存储 | 有稳定用户、明确同步需求后 |
| 团队日历/共享 | 中 | ¥20–40/座位/月，小团队 | 有 3–5 个团队真实试用后 |
| 插件市场分成 | 低（近期） | 15%–30% 抽成 | 审核/签名/结算体系完成，0.4 后 |
| 企业定制/支持 | 低 | 按项目 | 有明确企业客户时 |

### 为什么捐赠优先

- 不改变产品结构、不引入服务端、不需要账号；
- 验证“用户是否愿意为这个工具付费”的最小信号；
- 失败也不会留下半成品付费墙。

### 为什么云同步必须可选

- 与“本地优先”有张力：需要账号、服务端、加密、合规；
- 只能作为**可选附加**，本地功能不降级；
- 默认端到端加密，服务端不存明文；支持一键导出/删除；
- 没有同步需求时，产品体验必须完全一致。

## 3. 成本模型（量级，不是预算）

| 项目 | 量级 | 说明 |
|---|---|---|
| 代码签名证书 | ¥1k–4k/年（可选） | 无证书 SmartScreen 会拦，影响安装转化 |
| GitHub Releases / CI | 低 | 公开仓库 Actions 额度通常够 |
| 同步服务端 | $10–100/月起 | 取决于用户量与是否自建对象存储 |
| 支付通道 | 2%–5% | 爱发电/Stripe/Paddle 费率不同 |
| 支持人力 | 最大隐性成本 | 启动器问题碎片化，必须有 FAQ/日志导出 |

结论：**在没有稳定收入前不养常驻服务端**。云同步必须等到“有人明确要求并愿意预付”再做。

## 4. 对开源协议的影响

- 核心继续 **MIT**：允许商用、修改、再分发；不搞“开源版功能残缺”。
- 云同步/团队服务可以是独立闭源服务，但客户端同步协议与数据导出保持开放；
- 插件 SDK 保持宽松许可，允许第三方插件自由分发；
- 不做 CLA 强制转让；贡献者保留版权，项目方获得非独占使用许可即可；
- 若未来引入“open-core”，只允许**服务端/协作**闭源，不允许把已有本地功能搬进付费墙。

## 5. 退出策略

商业化失败时，产品仍要可用：

1. 停止收费服务，保留本地功能与数据导出；
2. 提前 6 个月公告，提供 JSON/Markdown/ICS 全量导出；
3. 服务端代码/协议尽量开源，允许社区自建；
4. 捐赠页保留，但不以“停止维护”威胁用户付费；
5. 不锁数据库、不做 DRM、不远程禁用功能。

## 6. 决策指标

在考虑云同步前，至少观察：

- 周活/月活与 7 日留存；
- 日程/笔记的真实使用频次（不是安装量）；
- 用户主动询问“能否多设备同步”的次数；
- 支持请求中与同步/备份相关的比例；
- 捐赠转化率（目标先做到覆盖签名/CI 成本）。

## 7. 结论

- **0.3–0.4：只做捐赠入口 + 本地功能**，不写付费代码；
- **0.5 之后**：若有明确同步需求，再做可选云同步，默认 E2EE；
- **团队版**：独立产品线，不污染个人版本地体验；
- **插件市场**：等审核、签名、结算三件事都有答案再谈。

这份决策可以随用户数据调整，但“本地核心免费、广告不做、功能不阉割”三条不调整。
